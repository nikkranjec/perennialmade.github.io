``` **One important correction from my previous version:** I would **not** use `bottom: 30vh`, `34vh`, etc. for this design. Your original was deliberately built around **`vw` positioning**, which means the text and giant wordmark maintain their relationship as the browser changes shape. Also, the original DC code had these exact responsive values: * Desktop TIKTOK: `bottom: 19vw` * Desktop INSTAGRAM: `bottom: 23.5vw` * Desktop contact: `margin: 0 0 -12.13vw 5vw` * Wordmark: `width: 115vw` * Wordmark: `margin-left: -8.21vw` * Wordmark bottom: `-4.71vw` * Mobile TIKTOK: `bottom: 27vw` * Mobile INSTAGRAM: `bottom: 39vw` * Mobile wordmark top: `-10.5vw` * Mobile wordmark bottom: `-1.3vw` Those relationships are what we want to preserve rather than manually pushing things around. If the **actual visual target is the footer exactly as it appeared in the old site**, the safest next step is to preserve the original footer's *entire layout hierarchy* even more literally and only delete the sections above it. That would avoid changing its geometry at all.
